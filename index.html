About

소개

저는 프레임워크를 사용하기 전에 웹이 어떻게 동작하는지 직접 구현하며 이해하는 것을 중요하게 생각합니다. 이 프로젝트에서는 DOM 선택, 이벤트 연결, 상태 관리, 비동기 데이터 처리까지 프론트엔드 핵심 흐름을 직접 코드로 구현했습니다.

학습 중심 프로젝트이기 때문에 UI 완성도뿐 아니라 로딩/에러/빈 상태, 폼 검증, 테마 유지처럼 실제 서비스에서 자주 마주치는 상황도 함께 다뤘습니다.

  • 사용자 이벤트 → 상태 변경 → DOM 업데이트 흐름 이해
  • 모바일 퍼스트 반응형 레이아웃 설계
  • 외부 API 연동과 비동기 상태 표현
